# تیپاکس‌یار — پیش‌نمایش کاربردی و پروژه Android

این بسته شامل یک پیش‌نمایش RTL قابل اجرا در مرورگر و پوسته Android WebView برای تبدیل به APK است.

## وضعیت واقعی
- فایل HTML و رابط فارسی: ایجاد شده.
- ثبت/ویرایش/حذف مرسوله: پیاده‌سازی شده در پیش‌نمایش.
- ذخیره محلی مرورگر: پیاده‌سازی شده.
- ورود CSV با تطبیق ستون و پیش‌نمایش: پیاده‌سازی شده.
- خروجی CSV سازگار با اکسل: پیاده‌سازی شده.
- ترتیب اولیه/معکوس/شروع از توقف دلخواه/مرتب‌سازی دستی: پیاده‌سازی شده.
- ثبت کد تحویل و وضعیت: پیاده‌سازی شده.
- اسکن دوربین، OCR، واردکردن مستقیم XLSX، مسیریابی جغرافیایی واقعی و اتصال رسمی Tipax: در این نسخه پیاده‌سازی نشده‌اند.
- APK: هنوز ساخته نشده؛ محیط ساخت فعلی Android SDK و Gradle نصب‌شده ندارد و دسترسی شبکه برای دریافت Android SDK ناموفق بود.

## پیش‌نمایش در ویندوز
فایل `app/src/main/assets/index.html` را در Chrome یا Edge باز کن. برای آزمایش از «بارگذاری نمونه» استفاده کن. داده‌ها در localStorage همان مرورگر ذخیره می‌شوند.

## ساخت APK با Android Studio
1. Android Studio و Android SDK را نصب/باز کن.
2. از SDK Manager، Android SDK Platform 35 و Build Tools مناسب را نصب کن.
3. این پوشه را با Android Studio باز کن و منتظر Sync Gradle بمان.
4. اگر Gradle/AGP نیاز به دریافت دارد، اتصال اینترنت لازم است.
5. از Build > Build APK(s) خروجی بگیر.
6. APK معمولاً در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

برای نسخه انتشار، از Build > Generate Signed Bundle / APK استفاده کن و keystore خودت را امن نگه دار.
